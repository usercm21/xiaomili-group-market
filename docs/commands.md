# 玩法与指令

所有指令格式为 `@机器人名称 #命令`，例如 `@小米粒 #帮助`；`@小米粒` 只是示例，接入其他机器人时换成它的实际名称。**“小米粒群友市场”是固定的游戏品牌名。**普通聊天不触发市场。

| 指令 | 作用 |
| --- | --- |
| `#市场状态`、`#市场版本`、`#市场记录` | 查看本人资产、版本与最近 10 条操作 |
| `#帮助`、`#排行`、`#上期排行` | 查看帮助、当前排行与已结算榜 |
| `#加入市场`、`#退出市场` | 加入或退出；退出会移除个人卡与可展示流水 |
| `#打工` | 赚取虚拟币；冷却 1 小时，每天最多 5 次 |
| `#银行 状态`、`#银行 存 50`、`#银行 取 50`、`#银行 升级` | 查看、存取与升级银行 |
| `#招募 群友`、`#放生 群友`、`#训练 群友` | 管理名下群友与训练 |
| `#夺取 群友`、`#夺取` | 指定或随机选择可操作目标 |
| `#回购自身`、`#决斗`、`#排位 群友` | 回购、随机决斗、让名下群友排位 |
| `#市场任务`、`#市场成就`、`#市场荣誉`、`#市场事件` | 查看每日任务、长期成就、月度荣誉和周事件 |

`#招募`、`#放生`、`#训练`、`#排位` 缺少目标时会列出候选；只有一个候选时直接执行。多个候选可在 60 秒内用 `#1` 等编号重发，最多显示前 20 名。昵称重名时也会列编号。保护对象、已退出者或不在可信群成员快照中的人不可被操作。

默认月榜不清空虚拟币、身价、银行与关系；每月重置竞争积分。银行利息按实际持有时间计算，每日 0.5%，可计息本金上限 40,000，利息进入现金。虚拟币、展示票券和徽章仅属于游戏内容。
